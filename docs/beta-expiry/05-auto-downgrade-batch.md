# 05. 자동 무료 전환 배치

## 작업 범위

만료일에 도달한 베타 프리미엄 사용자를 무료 플랜으로 자동 전환.

## 실행 시점

매일 자정 (KST). 알림 배치와 동일한 스케줄러에서 실행 가능 (별도 메서드).

## 대상 조건

```sql
premium_expires_at < now()
AND is_premium = true
AND premium_source = 'beta_promo'
AND 별도 정기 구독 미시작
```

"별도 정기 구독 미시작"은 현재 구독 모델에 따라 다름. 일반적으로:
- 활성 구독 레코드가 없음
- 또는 구독 상태가 `expired` / `cancelled`

## 처리 내용

```
is_premium = false
premium_source = null
사용자 알림 큐에 "전환 완료 모달 표시" 플래그 적재
```

전환 후 사용자의 다음 앱 진입 시 결과 안내 모달 표시되어야 함.
플래그는 별도 테이블 또는 사용자 필드로 관리.

## 결과 안내 모달 트리거

옵션 A: 사용자 테이블에 `show_downgrade_modal: boolean` 필드 추가
- 전환 시 true로 설정
- 클라이언트가 모달 표시 후 false로 업데이트하는 API 호출

옵션 B: 알림 테이블에 in-app notification 레코드 생성
- 기존 알림 시스템이 있으면 활용

**기존 알림 시스템 구조 확인 후 결정**

## 베타 할인 쿠폰 유지

무료 전환되어도 `beta_discount_eligible_until`은 유지.
사용자가 D+30 이내에 재구독 결정 시 할인 적용 가능.
