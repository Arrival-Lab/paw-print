# 발자국 시드 데이터 가이드 (강아지 설기 · 고양이 코코 · 새 나나)

> 반려동물 안 키워본 사람을 위한 "현실적인 입력값" 모음. 데모/QA 계정에 수동으로 채워 넣을 때 그대로 베껴서 사용 가능.
> 모든 데이터는 **api.pawprintapp.link** (배포 백엔드) 기준.

---

## 0. 한국 펫 보호자 상식 (배경)

- **가장 흔한 견종**: 말티즈 > 푸들/포메 > 믹스 > 시츄. 소형견(10kg 이하) 비중이 압도적.
- **가장 흔한 묘종**: 코리안 숏헤어(코숏) > 러시안 블루 > 페르시안. **"치즈태비/고등어태비/삼색"** 같은 무늬 표현이 자주 쓰임.
- **가장 흔한 반려조**: 사랑앵무(Budgerigar) > 모란앵무 > 왕관앵무 > 코뉴어 > 십자매·문조.
- **사료 브랜드**: 로얄캐닌(압도적) · 사이언스 다이어트 · 오리젠 · 아카나.
- **자주 가는 동물병원 패턴**:
  - 동네 1차: `"OO동물병원"`, `"행복한동물병원"`, `"코코동물병원"`
  - 24시: `"24시 청담우리동물병원"`, `"이리온 24시 강남"`, `"VIP 동물의료센터"`
  - 조류 전문: `"충현동물병원"`(천안 본원+분점), `"청담조류전문동물병원"`, `"VIP 의료센터 조류과"`
- **진료비 체감 (서울 기준)**: 진찰 1.5~3만 / 백신 3~6만 / 혈액검사 8~15만 / 스케일링(전신마취) 30~50만.
- **조류 진료비**: 진찰+분변 5~8만 / 클라미디아 PCR 10~15만 / 부리·발톱 손질 1~3만 / 종합검진 15~25만. **조류는 1차 병원에서 못 보는 곳이 많아 전문 병원 거리 멀어도 가야 함.**

## 9. 커뮤니티 게시글

### 응급
1. **"설기가 초콜릿 한 조각 먹은 것 같아요 ㅠㅠ"**

   - 댓글: 24시 즉시 / 테오브로민 계산기 링크 / 토하게 하는 법은 위험

2. **"나나(사랑앵무)가 케이지 바닥에 부풀어서 앉아있어요"**
   - 본문: "평소엔 활발한데 오늘 아침부터 깃털 부풀리고 졸린 듯 눈 감고 있어요. 새는 아프면 숨기는 거 맞나요?"

3. **"5살 말티즈 스케일링 비용 얼마 정도 드셨나요?"** — 댓글: 30~50만 / 발치 있으면 더 / 마취 전 혈액검사 필수

5. **"사랑앵무 부리 손질 어디서 하시나요?"** — 댓글: 충현 본원/분원 / 청담조류전문 / 직접 손질 위험(혈관)

## 10. 입력 순서 추천

1. **회원가입** — 데모 계정 또는 본인 계정
2. **펫 3마리 등록** — 이미 완료 ✅
3. **FoodInfo 입력** — 각 펫에 §2 의 currentFood/allergies/forbiddenFoods/notes
4. **진료기록** — 오래된 것부터 시간순 (병원명은 §3 그대로 — autocomplete 캐시 검증)
5. **예방접종 알림** — 설기 1 → 코코 1 → **3번째 등록 시 모달 확인**
6. **진료일정** — 설기 2026-05-25 건은 "방문 완료 → 진료기록 작성" 으로 양방향 링크 검증
7. **HealthMetric 체중** — 각 펫. 나나는 그래프 검증용으로 최근 1개월에 4개 이상
8. **OCR** — 영수증 3회 후 4번째 시 PremiumModal
9. **케어 공유** — 설기에 가족 1명, 2번째 시 모달
10. **커뮤니티 게시** — 응급 2 + 일반 3 + 자랑 2

## 11. 부록 — 자주 쓰는 표현

### 강아지·고양이
- **"내원"** / **"처치"** / **"투약"** / **"이상소견 없음"** / **"경과관찰"**
- **"보호자"** = 주인 / **"식욕부진" / "기력저하" / "활력 양호"**
- **"BCS 5/9"** = Body Condition Score (1~9, 5 정상)
- **"DHPPL"** = 강아지 종합백신 (디스템퍼·간염·파보·파라인플루엔자·렙토스피라)
- **"FVRCP"** = 고양이 종합백신 (허피스·칼리시·범백)

### 조류
- **"환우(換羽)"** = 깃털 갈이 (정상, 봄·가을)
- **"납막(cere)"** = 콧구멍 위 부위. 사랑앵무 성별 판별 (수컷 파랑, 암컷 갈색).
- **"PBFD"** = Psittacine Beak and Feather Disease (앵무새 부리·깃털병, 치명)
- **"클라미디아"** = 인수공통감염병. 분양 직후 PCR 필수.
- **"발찌(legband)"** = 분양처 식별 번호.
- **"방사"** = 케이지 밖 자유 비행 시간.
- **"합사"** = 다른 개체와 같이 사육.
- **"테플론(PTFE) 가스"** = 코팅팬 가열 시 발생, 새에게 치명적.
