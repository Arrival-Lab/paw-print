베타 테스트 시작하기

발자국 베타 테스트, 신청부터 설치까지 한 번에 안내해 드릴게요. 폼 작성에서 TestFlight 설치까지 보통 5분이면 끝나요. (초대 메일 받는 시간은 별개로 1–2일 소요)

베타 테스트 시작하기 베타 테스트 안내 ← 고객센터
1

구글 폼으로 베타 신청하기

아래 폼에 이메일 주소를 남겨 주세요. 적어 주신 메일로 TestFlight 초대를 보내드려요. 현재는 iOS 만 진행 중이고, Android 베타는 준비 중이에요.

→ 베타 신청 폼 열기

왜 폼이에요? 신청자분들을 한 곳에 모아서 TestFlight 초대를 빠뜨리지 않고 차례대로 보내드리려고요. 메일로 직접 알려주셔도 되지만 폼이 가장 확실해요.
2

초대 메일 받기 (1–2일 소요)

폼 작성 후 영업일 기준 1–2일 안에 폼에 적어 주신 메일 주소로 "발자국 베타 테스터로 초대합니다" 라는 TestFlight 초대 메일이 도착해요.

메일이 안 보이세요? 스팸함 / 프로모션 탭을 먼저 확인해 보시고, 그래도 없으면 chaeon.studio@gmail.com 으로 알려 주세요. 다시 보내드릴게요.
3

App Store 에서 TestFlight 앱 먼저 설치

iOS 베타 테스트는 Apple 의 TestFlight 앱을 통해 진행돼요. 아직 설치하지 않으셨다면 App Store 에서 "TestFlight" 를 검색해 받아 주세요. (무료, Apple 공식 앱)

iOS 15.1 이상이 필요해요. 설정 → 일반 → 정보 에서 iOS 버전을 확인하실 수 있어요.

App Store 에서 TestFlight 검색 → "받기" 눌러서 설치

4

초대 메일에서 TestFlight 링크 누르기

초대 메일을 베타 테스트에 쓰실 기기(아이폰/아이패드)에서 열어 주세요. 메일 본문에 "open TestFlight" 또는 "TestFlight app" 링크가 있어요. 둘 중 아무거나 누르시면 TestFlight 앱이 열려요.

초대 메일에서 노란 동그라미 친 링크 중 아무거나 눌러 주세요

5

TestFlight 안에서 "설치" 누르기

TestFlight 가 열리면 발자국 앱 페이지로 이동돼요. "설치" 버튼을 누르시면 베타 빌드가 기기에 깔려요.

발자국 앱 페이지의 "설치" 버튼

설치가 끝나면 홈 화면에 발자국 아이콘이 생겨요. 아이콘 옆에 작은 주황 점이 보이면 베타 빌드라는 표시예요.
6

앱 열기 · 피드백 보내기

같은 페이지에서 "열기" 로 발자국을 바로 실행하실 수 있어요. 옆에 있는 "피드백 보내기" 버튼은 TestFlight 안에서 의견·버그를 바로 보내는 통로예요. 스크린샷도 함께 첨부할 수 있어요.

"열기" 로 앱 실행, "피드백 보내기" 로 의견 전송

앱 안에서 스크린샷 (전원 + 볼륨업) 을 찍으면 TestFlight 가 자동으로 "피드백 보내기" 창을 띄워 줘요. 메모만 적어서 보내시면 돼요. 가장 빠른 신고 방법이에요.
7

새 빌드 업데이트 받기

제가 새 빌드를 올릴 때마다 TestFlight 가 알려 드려요. 받는 방법은 두 가지예요.

  • 자동 업데이트 (추천) — TestFlight 앱 → 발자국 → "자동 업데이트" 토글을 켜 두시면 새 빌드가 백그라운드에서 자동 설치돼요. (기본값: 켜짐)
  • 수동 업데이트 — 자동 업데이트가 꺼져 있으면, TestFlight 앱을 열었을 때 발자국 옆에 노란 점이 떠요. 들어가서 "업데이트" 버튼을 누르시면 돼요.

TestFlight 푸시 알림을 켜 두시면, 새 빌드가 올라오는 순간 "업데이트가 있어요" 알림을 받으실 수 있어요. 발자국 앱 자체의 알림과는 별개예요.

중요 — 베타 빌드는 90일 후 만료돼요. 만료된 빌드는 실행 시 "이 베타는 만료됐어요" 알림이 떠요. 이때는 TestFlight 에서 최신 빌드를 다시 받으시면 돼요. 제가 만료 전에 새 빌드를 올려두려 노력하고 있어요.
