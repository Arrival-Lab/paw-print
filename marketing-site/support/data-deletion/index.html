이 안내는 계정은 유지하면서 일부 데이터만 삭제하고 싶은 경우를 위한 것입니다. 계정 자체를 삭제하시려면 계정 삭제 안내를 참고해주세요.

앱 안에서 직접 삭제

발자국 앱 안에서 거의 모든 종류의 데이터를 개별적으로 삭제할 수 있습니다.

데이터 종류위치
반려동물 프로필 (해당 펫의 모든 진료기록·다이어리 함께 삭제)펫 상세 → 휴지통 아이콘
진료기록 (병원 방문 기록)기록 → 진료 → 항목 길게 누름 → 삭제
진료일정기록 → 진료 → 일정 상세 → 삭제
예방접종 기록기록 → 백신 → 항목 → 삭제
건강 수치 (체중·BUN·크레아티닌 등)기록 → 수치 → 휴지통 아이콘
건강 다이어리다이어리 → 항목 → 더보기 → 삭제
일상 케어 항목 (산책·사료·영양제 등)기록 → 일상 → 편집 → 삭제
커뮤니티 게시물·댓글커뮤니티 → 본인 게시물 → 더보기 → 삭제
케어 공유 멤버펫 상세 → 함께 돌보는 사람 → 멤버 제거
프로필 사진더보기 → 프로필 편집 → 사진 제거

삭제는 요청 즉시 처리되며, 30일 이내에 클라우드 저장소(AWS S3)에서도 영구 삭제됩니다.
